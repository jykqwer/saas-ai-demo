# API 与集成

## REST API
- 提供完整 OpenAPI 文档，支持主流语言 SDK（Python / Node.js / Java / Go）。
- 认证方式：API Key 或 OAuth2 Client Credentials。
- 提供沙箱环境，方便安全联调。

## Webhook
- 支持业务事件订阅：订单创建、状态变更、数据同步完成等。
- 支持自定义签名校验与重试策略。

## 办公软件集成
- 官方对接企业微信、钉钉、飞书：组织架构同步、消息通知、审批打通。
- 支持主流 BI 工具（如 Power BI、Tableau）通过 API 拉取数据。

## 集成最佳实践
- 建议使用沙箱环境先行联调，再切换生产环境。
- 关注接口限流与幂等设计，保障数据一致性。
- 可联系技术顾问做集成方案评审。
