# 常见问题 FAQ

## 忘记密码怎么办
在登录页点击「忘记密码」自助重置；管理员也可在控制台代成员重置密码。连续输错会临时锁定账号，通常 15 分钟自动解锁。

## 如何导出数据
在「数据」模块选择导出范围，支持 CSV 与 API 导出；企业版可配置定时导出。

## 支持哪些单点登录
支持 SAML 2.0 与 OIDC，可对接 Azure AD、Okta、飞书、企业微信等身份源。

## 私有化部署需要什么环境
推荐 Kubernetes 1.24+ 或 Docker Compose，最低 4 核 8G 内存，数据可离线保留在客户环境。

## 如何联系人工客服
可在官网右下角联系在线客服，或通过系统内「转人工」提交联系方式，工作时间（9:00-18:00）内响应。

## 免费试用可以延期吗
标准版试用 14 天，试用到期后如需延期，可联系销售申请演示环境或试用延期。
