# 数据安全与合规

## 数据加密
- 传输加密：所有链路使用 TLS 1.2+ 加密。
- 存储加密：数据库与对象存储采用 AES-256 静态加密。
- 敏感字段：手机号、身份证等字段单独脱敏存储。

## 访问控制
- 支持 SSO 单点登录（SAML 2.0 / OIDC）。
- 细粒度 RBAC 权限模型，可按角色、部门、数据范围授权。
- 完整审计日志：记录登录、操作、导出等关键行为。

## 合规认证
- 通过等保三级测评。
- 提供年度渗透测试报告与安全白皮书。
- 支持与安全团队进行专项合规对接（如数据出境评估）。

## 私有化数据主权
- 私有化部署时数据完全由客户掌控，云枢科技不接触客户数据。
- 支持数据导出（CSV / API）与删除策略，满足数据删除权要求。
